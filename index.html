Top Bar — Button Guide
Show / Hide Preview
Toggles the document preview panel. Use this to see the generated policy document side-by-side with the form, or hide it to give the form more space.
✏️ Edit
Enters edit mode so you can directly change text in the generated preview — useful for minor wording tweaks without re-filling the form. The formatting toolbar appears when edit mode is active.
Files
Opens the File Explorer so you can browse, organise into folders, and reload previously saved businesses from the shared database.
Save to Database
Saves the current form data (company info, directors, settings) to the shared database as a named entry. You can load it again later from the Files explorer.
ClientReg
ClientReg now lives on the start panel on the right-hand side, which is on screen until a document is generated. Type a company name, client code or registration number into its search box and matching clients appear underneath as you type — pick one to go straight to its import panel, or press Search ClientReg for the full list. You can also use Import a ClientReg .xlsx file to upload an export as before. Either way, company details, directors and shareholders fill in automatically. Always check the imported details: the register is often out of date.
Generate
Builds the full policy document from the current form data and displays it in the preview panel. Click this after completing the form or after making changes.
Print / PDF
Opens the browser print dialog so you can print the document or save it as a PDF. This button only appears after a document has been generated.
⚙ Settings
Opens a dropdown with your display name, Discard Preview Edits, the Keyboard Scrolling Tutorial, and the Admin Panel.
