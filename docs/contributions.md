## Q&A preparation

The brief states that **all members should be able to answer any question
posed**. Before the presentation, each member should be able to, without notes:

- [ ] Explain the difference between a spreadsheet row and a stored record, and
      why it matters to this client
- [ ] Define metadata and give three fields from the envelope and what each answers
- [ ] Name the information quality dimensions and give the shop's own example of each
- [ ] Explain why validation has two severities rather than one
- [ ] Explain what POPIA requires and name the four questions the shop must be
      able to answer
- [ ] Explain why the team did not recommend AI forecasting for this client yet
- [ ] Explain islands of data and single source of truth
- [ ] Explain the difference between configuring and customising, and why it matters
- [ ] Walk through the roadmap and defend the ordering
- [ ] Name one thing the team advised the client **not** to spend money on, and why
- [ ] Drive the live demonstration — capture a sale, break a rule, generate an
      invoice, produce a POPIA report
- [ ] Say honestly how AI was used on the project
